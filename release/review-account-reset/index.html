Set Apple’s review password

This is only for the separate App Review account. Students continue to sign in with email codes.

Use a unique password of at least 16 characters. Save it securely; Apple needs it in the private App Review Information form.

The recovery link is checked by Supabase. The password goes directly to Supabase over HTTPS when you choose Save. This page stores neither the password nor a sign-in session.
