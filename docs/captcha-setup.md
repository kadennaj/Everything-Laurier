# Sign-in CAPTCHA — October 21, 2026

Cloudflare Turnstile widget: **Everything Laurier sign-in**, managed mode, restricted to `everythinglaurier.ca`, with pre-clearance disabled. The public site key is in `src/lib/captcha.ts`. The private key was entered directly into Supabase Auth's Attack Protection settings with the owner's permission; it is not included in source, environment examples, screenshots or app exports.

The hosted page at https://everythinglaurier.ca/captcha/ loads in a web iframe or native WebView only after a user chooses to request/resend an email code. It receives a request correlation value and an allowlisted parent origin in the URL fragment; no email, GPS or transcript is passed. Web messages require matching iframe, exact origin and current request identifier. Native navigation permits only the hosted page, Cloudflare challenge origin and the blank/srcdoc frames required by Turnstile. Native browser storage is enabled for the security check; the map retains its own independent storage restrictions.

`requestEmailCode` requires a token and passes it to Supabase's `signInWithOtp` options. Tokens stay in memory, bind to the entered email, are cleared before each send attempt and must be refreshed after an attempt or expiry. The client uses a conservative two-minute freshness window. Browsing and existing signed-in sessions do not load a challenge. Email-code verification retains Supabase's existing server verification and rate limits.

Verification so far: the hosted production widget visibly completes in the web sign-in flow; live Auth requests with missing or invalid tokens return HTTP 400 `captcha_failed`. After correcting native frame/storage requirements, Kaden confirmed the iPhone security check finishes and the requested email code arrives. The widget dashboard's analytics can lag and a missing-token request may not reach Cloudflare; Supabase performs siteverify when an actual token is supplied. Never disable server CAPTCHA merely to make client tests pass.

After changing domains, update the widget hostname restriction, hosted parent-origin allowlist and app page URL together. After secret rotation, update Supabase Auth directly, never the public app. Rebuild/reinstall older phone builds that lack token support. Privacy and cookie notices were updated to disclose this security provider; no marketing CAPTCHA SDK or analytics package was added.
